This tool helps you build the code for new or updated announcements and videos. It does not save anything automatically — when you're done, you'll copy the result and paste it into the site's files on GitHub yourself. See the "How this works" section at the bottom if you're new to this.

How this works

  1. On GitHub, open announcements-data.js or videos-data.js, copy everything in the file, and paste it into step 1 above.
  2. Click an existing entry to edit it, or add a new one.
  3. Fill out the form and save — this only changes what you see on this page, nothing is sent anywhere yet.
  4. Copy the finished code from step 3.
  5. Back on GitHub, open the same file, select all (Ctrl/Cmd+A), delete, paste in the new code, and commit the change. The live site updates within a minute or two.

If you're attaching a PDF or uploading a video file, remember to also upload that actual file into the pdfs or videos folder on GitHub — this tool only handles the text/code side, not file uploads.
